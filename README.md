# ShaderPit



**ShaderPit** is a Blender addon designed to create and customize material variations quickly and intuitively.



It combines procedural controls with direct artistic input, allowing you to build, modify and mix materials without having to manually rebuild complex shader setups.



## About



ShaderPit is a personal tool developed by Pit Bibiloni to simplify and speed up material creation and look-development workflows in Blender.
I'm a 3D artist, not a software developer, so this project is primarily focused on the artist's workflow, usability, and experimentation rather than software development itself.
The addon is being developed as an ongoing personal project, with new features and improvements added based on practical production needs.



## Features



### Grunge

Create procedural grunge masks and control:

* Detail
* Roughness
* Lacunarity
* Seed
* Distortion
* Mask Contrast
* Color
* Blending
* Height
* Texture-based grunge
* Texture mapping and tiling

### Dirt

Add and customize dirt variations with controls for:

* Blending
* Roughness
* Color

### Roughness

Generate procedural roughness variations using:

* Roughness
* Noise Scale

### AO

Control ambient occlusion variations through:

* Color
* Blending
* Amount

### Color

Quickly modify the material appearance using:

* Material selection
* Hue
* Curves

### Material Mixer

Combine materials using procedural masks and control:

* Blending
* Noise
* Contrast
* Height

### Live Paint

Paint directly on the material mask inside Blender's Texture Paint workflow.
Live Paint allows you to combine procedural material generation with direct manual control.



## Requirements

* Blender 5.2 or newer

## Installation

1. Download the latest ShaderPit `.py` file.
2. Open Blender.
3. Go to **Edit → Preferences → Add-ons**.
4. Click **Install...**
5. Select the ShaderPit `.py` file.
6. Enable the addon.
